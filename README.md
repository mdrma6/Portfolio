# Ruhi Mohammed Anana — Portfolio

Static site (HTML/CSS/JS, no build step).

- Open `index.html` in a browser, or host the folder on GitHub Pages / Netlify / Vercel.
- `styles.css` — theme tokens at the top (`:root`).
- `script.js` — projects (`P`), skills (`S`), certificates (`C`) and image paths (`IMG`). Set `LINKS.github` to show the GitHub button.
- `assets/` — certificate images and resume page image.
- `ruhi-portfolio-single-file.html` — same site as one self-contained file.
